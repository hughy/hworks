# Projects

For each project, create `<name>/README.md` and `<name>/STATE.md` from the hoffice engine's `templates/project-README.md` and `templates/project-STATE.md`. Create `DOCS.md` from engine `templates/DOCS.md` and directories `sessions/`, `decisions/`, `notes/`, `published/`, and `mirrors/` as they gain content. Use a README rather than a placeholder file if an empty directory needs to be committed.

Add the project to the instance root `README.md` project table and register its repositories in `repos/`. `README.md` is the brief; `STATE.md` is the present, not a log. Read instance `AGENTS.md` before editing either.
