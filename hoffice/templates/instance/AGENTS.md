# Instance agent instructions

This directory is a hoffice instance: shared project memory, not the engine.

Find the hoffice engine through `$HOFFICE_HOME`, else the single line in `$HOFFICE_CONFIG_DIR/home`. `$HOFFICE_CONFIG_DIR` defaults to `~/.config/hoffice`.

Before working here, read `<engine>/docs/instance-agents.md` and follow it. If the engine cannot be found or that file cannot be read, stop and ask for the engine path rather than guessing the rules.
